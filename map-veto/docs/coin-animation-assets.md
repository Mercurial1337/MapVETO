# Global coin animation artwork

The event creation/edit forms offer an event logo, not a per-event coin or font.
The two coin animations will be maintained as global website assets when the
finished artwork is supplied. No replacement animation has been wired in yet.

Send the designers these specs:

- Two square GIFs, **448 × 448 pixels each**, matching the previous tournament files.
- `coin-flip-a.gif`: animation ends with the original first team winning.
- `coin-flip-b.gif`: animation ends with the original second team winning.
- Use identical canvas dimensions and duration, with the coin centered and enough
  space that it is not clipped. Leave the winning result clearly visible at the end.
- Prefer a single-play export. Keep frame rate and file size modest; aim for
  20–24 fps and under 2 MB each where visual quality allows.
- Artwork size is the export resolution; the page will scale it down to fit.

The old GIFs are 448 × 448, 358 frames, 7.16 seconds and about 4.6 MB apiece.
Their dimensions are a reference, not a requirement to reproduce that weight.
The animation must show the server's actual winner; it must not determine the
winner itself or add a delay to the authoritative veto timer.
